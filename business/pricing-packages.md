# Pricing Packages

## Rules
- Fixed price only with a written scope; anything beyond it goes through add-ons or a change request.
- 50% milestone up front for projects above $400 (Upwork milestones / Fiverr handles escrow).
- Run `npm run estimate` before quoting anything custom.
