## Profile overview

I build reliable automated tests for web applications, so your team can ship without fear of breaking things.

**What I deliver**
- End-to-end tests with **Playwright + TypeScript**, structured with the Page Object Model
- **REST API tests** in the same framework
- **CI/CD integration** (GitHub Actions): tests run on every pull request and on a schedule
- **HTML reports** with screenshots, videos and traces for every failure
- **Clear bug reports**: steps to reproduce, evidence, severity, and a suggested root cause

**Why work with me**
- Full-stack background: I read your code, understand your API, and write tests that target real risks.
- **Zero-flake policy**: no fixed sleeps, isolated test data, and every suite verified with repeated runs before handover.
- I separate *application bugs* from *test problems*, so you never chase false alarms.
- AI-assisted workflow: faster delivery, with every test reviewed and executed by me.

**Portfolio:** working sample repository with 24 tests, CI pipeline and sample reports → `https://github.com/<your-user>/playwright-qa-automation-portfolio`

**Typical projects:** smoke suites for MVPs, regression suites before a launch, migrating Selenium/Cypress to Playwright, adding tests to CI, fixing flaky tests.

Send me your app URL and the 3 flows that worry you most, and I will reply with a test plan and a fixed quote.
